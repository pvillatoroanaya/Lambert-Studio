T+0Starting point

One assignment: find an orbit from two sightings

A ground station measures a satellite twice: azimuth, elevation and range, two and a half hours apart. From those six numbers, find the complete orbit. This is Lambert's problem, the same mathematics used to plan every interplanetary mission.

  1. Convert each sighting (azimuth, elevation, range) from the station's horizon frame into Earth-centred inertial coordinates, using sidereal time.
  2. Solve Lambert's problem with the universal-variable method (Curtis, Algorithm 5.2) to get the velocities.
  3. Turn position and velocity into the six classical orbital elements.
  4. Result for the assignment: an elliptical orbit with a = 28,184 km, e = 0.768, i = 20.34°, period 13 h 04 min.

T+2How it was built

From a script to a studio, one verified step at a time

The project grew in stages. Each stage had to pass the tests from every earlier stage before the next began.

  1. Phase 1 · foundation

    Rebuild and verify the solver

    Time systems, coordinate frames, a universal-variable Lambert solver and orbital elements, checked against textbook worked examples and physical invariants: energy and angular momentum conserved to 10⁻¹⁵, and propagation landing on the second observation to within 10⁻¹¹ km.

  2. Phase 2 · application

    A desktop app with a web-grade 3D engine

    Python keeps the physics and serves a small JSON API on the local machine; the interface is drawn with Three.js (WebGL) and Plotly. After the embedded Qt browser crashed on this machine, the window moved to Microsoft Edge's app mode, with crash logging and automatic recovery.

  3. Phase 3 · real data

    Satellites, asteroids and the planets

    CelesTrak element sets for thousands of satellites, NASA/JPL close approaches and Horizons trajectories, and the DE440s ephemeris via Skyfield, with offline caching so the app keeps working without a connection.

  4. Phase 4 · engineering tools

    Manoeuvres and perturbations

    A manoeuvre planner that derives every burn from state vectors, and a numerical integrator (SciPy DOP853) with J2 and an exponential atmosphere, checked against the analytic J2 drift rates.

  5. Phase 5 · mission design

    Gravity assists and multi-revolution Lambert

    A vectorised Lambert solver (10× faster, identical to 10⁻¹¹ km/s) with multi-revolution solutions, a beam search over launch dates and flight times, and patched-conic flyby physics. Widening the search took Cassini's route from 9.7 to 6.9 km/s and onto its historical dates.

  6. Phase 6 · experience

    Mission playback, free camera, guided inputs

    A full-screen, cinematic playback of any mission; a fly-anywhere camera; and recommended values with sources: NASA Deep Space Network stations, flown engines, real spacecraft masses and a launch-window finder.

  7. Phase 7 · delivery

    Tests, packaging and the course hand-in

    A pytest suite covering the physics and the API, browser-driven interface tests, a stand-alone Windows build with PyInstaller, and a generated single-file version of the solver that meets the assignment's format.

T+5Lessons

What building it taught

Test the behaviour, not the screenshot

A page can look right and still be wrong. Driving a real browser to press keys, double-click and play missions caught bugs that screenshots never showed.

Search width changes the answer

Judged leg by leg, a route that looks expensive early can win later. A 10× wider beam search turned Cassini from worse-than-direct into the historical route.

Know where the maths breaks

Galileo's Earth-to-Earth loop took exactly two years, so start and end points coincide and Lambert's problem is undefined. The app flies a nearby loop and says so.

The platform is part of the system

An embedded browser crashing in native code, and Windows silently redirecting where Python saves files, were fixed by measuring first and changing architecture second.

Model limits

  • Patched conics: each planet's gravity acts alone; no deep-space burns.
  • Perturbations: J2 and an exponential atmosphere; no Sun or Moon pull.
  • Exact resonant loops (start = end) are approximated.
  • The assignment's station uses a spherical Earth, as specified.
